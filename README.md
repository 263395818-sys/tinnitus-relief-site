# App Store 支持页部署说明

将本目录中的以下文件上传到任意 HTTPS 静态网站：

- `index.html`
- `privacy.html`
- `style.css`
- `icon.png`

可使用的方案：

- GitHub Pages
- Gitee Pages
- Cloudflare Pages
- Netlify Drop
- Vercel
- 自有网站

建议最终 URL：

- 支持 URL：`https://你的域名/index.html`
- 隐私政策 URL：`https://你的域名/privacy.html`

App Store Connect 不接受邮箱作为支持 URL，必须提供可公开访问的网页地址。
